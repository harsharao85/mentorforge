# Cloud Guild — Northstar Consulting Community of Practice

**Type:** Community of Practice
**Membership:** ~120 members across Cloud practice and cloud-adjacent roles
**Meets:** Every other Thursday, 12pm PST / 3pm EST / 8pm GMT

---

## Who We Are

The Cloud Guild is the technical community for cloud practitioners at Northstar. We cover AWS architecture, infrastructure-as-code (Terraform, CDK), cloud-native application patterns, FinOps, security, and the intersection of cloud with data (Databricks on AWS, Unity Catalog, cross-cloud data sharing).

Membership is open to anyone interested in cloud — you do not need to be in the Cloud practice.
